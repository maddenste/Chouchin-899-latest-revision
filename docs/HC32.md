# Flash the movement chip (HC32)

Use **HC32 V15** for the HDSC HC32L130J8TA board. The release HEX and BIN both
contain the **entire 64 KiB firmware**, not a patch to apply yourself.
Use the HEX with XHSC; the BIN is the same flash contents in raw form.
This is our modified firmware, not an original factory-firmware download.

## 1. Download and back up

Download **Chouchin-899-HC32-V15-20261001.hex** and check its hash in
[the release](https://github.com/maddenste/Chouchin-899-latest-revision/releases/tag/v2.0-rc1).
Preserve your own original backup before erasing. If needed, follow
[the Keil backup guide](HC32_BACKUP.md); keep that backup private.

## 2. Connect for UART programming

Use the confirmed DAPLink probe with UART pins and **XHSC MCU Programmer V2.23**.
Obtain the vendor tool separately.

| Programmer pin | HC32 board pad |
| --- | --- |
| U_TX | DIO |
| U_RX | CLK |
| GND | GND |
| Bench supply 3.3 V | BOOT, held high during programming |

These UART connections are intentional. They differ from SWD debug wiring.
Do not connect programmer 3V3, 5V or nRST. Power the clock from the bench supply,
not two competing supplies. See [hardware](HARDWARE.md) for cautions.

1. With board power off, connect the wires. Leave DAPLink USB unplugged.
2. Hold BOOT at 3.3 V, then power the board.
3. Plug DAPLink into USB **after** the board is powered.

## 3. Set XHSC and write

| XHSC setting | Value |
| --- | --- |
| Target MCU | HC32L13x8/HC32F030x8 |
| Baud | 115200 |
| HEX file | Chouchin-899-HC32-V15-20261001.hex |
| COM port | Your probe's actual serial port |
| Start address | 00000000 |
| Page size / page count | 512 / 128 |
| Flash size | 64K |
| Operation | Chip Erase |
| Erase / Program / Verify | Checked |
| Blank Check / Encrypt / Auto Number | Unchecked |

Click **Execute**. Keep BOOT high and power steady until programming and
verification finish. The selected operation erases and writes the whole chip.
The family selector includes HC32F030; our tested chip is HC32L130J8TA only.

## 4. Restart normally

Power off, disconnect BOOT from 3.3 V, then power on.
Do not leave BOOT held high during normal use.
Install [Wi-Fi R16](FLASHING.md) on the TXW separately if needed.

## What V15 changes

- Accepts movement and battery-saving selectors at the end of +TIME.
- Fixes overnight restarting while retaining original battery checks.
- Allows indefinite second-hand parking after it reaches 12.
- Supports daily and temporary DST waking with minute precision.

No TXW script writes the HC32. V15 modifies the original vendor implementation;
its underlying redistribution rights remain unresolved in the project notices.
The raw BIN SHA-256 is
B1D557505163B973FD59B20AA80246DA853F2F4A3D3AC555D53715180C533A60.
The HEX checksum is recorded in [release identifiers](RELEASE_IDENTITY.md).
